# 联网检索与下载问题清单

更新日期：2026-11-15（Asia/Shanghai）。本文件不包含单位名称、账号、密码、Cookie 或登录令牌。v1.0.0 已移除特定单位入口与凭据查看器。

## 已实现并完成实测

- PDF 打开：修正 Tauri 前端缺失文件路径授权范围的问题，改为后端按库记录 ID 验证并打开 PDF。桌面点击后已在 WPS 中显示真实论文。文件迁移后可重新关联同名原 PDF。
- Codex 阅读总结：使用登录后的 `codex.exe exec`，通过 stdin 传递有界论文材料，输出经过 JSON Schema、中文结构及标签证据校验。真实 PDF 已通过实测。
- IEEE 检索：Codex 联网检索真实候选，返回 IEEE 来源、作者、年份、出版物、质量理由与局限；未知引用次数保留为空，不编造。真实检索已通过。
- 公开 PDF 下载：IEEE/arXiv HTTPS 地址校验、重定向检查、80 MB 大小限制、PDF 文件头检查；公开 arXiv PDF 下载已实测通过。下载完成接入现有导入与分析队列。
- 摘要：清除关键词、作者脚注、机构说明等污染，新增数据库迁移 6 修复旧记录。当前实际库中三篇摘要均已清理，数据库完整性检查为 `ok`。
- 作者信息：独立显示全部署名、按署名顺序的第一作者、明确标注的通信作者及证据；从完整本地论文库生成同署名和潜在合作团队候选。

## 1. 机构订阅 PDF 的无人值守下载尚未完成端到端验证

**历史验证边界**：旧版曾通过用户已有的机构访问会话看到订阅结果，但没有验证凭据，也没有完成从受限阅读页到自动下载导入的完整链路。公开文档不保留单位名称、域名或会话细节。

**遇到的问题**：受限阅读页可能只显示空白页面或由机构代理重复改写路径，无法得到可核验的 PDF 文件。当前不能把机构全文下载标记为已验证成功。

**v1.0.0 能力**：提供 IEEE 官方页面的隔离窗口和系统浏览器入口；公开 PDF 仍可校验后自动导入。软件不内置单位入口、账号或凭据查看器。

**当前可用操作**：在 IEEE 或系统浏览器中使用用户自己的机构访问方式；若下载未触发自动导入，保存到本机后使用“Import PDF”。公开全文可直接使用“下载公开 PDF 并导入”。

**仍待验证**：机构登录后的 IEEE 下载事件是否触发以及导入是否成功；验证码、SSO 跳转和订阅范围需按实际页面处理，不绕过认证或访问限制。

## 2. Codex 检索进程不能复用浏览器中的机构登录会话

Codex CLI 使用自己的账号登录；机构访问 Cookie 属于浏览器会话。检索进程只接收自然语言需求及可选参考论文的有界题名/作者信息，不接收机构密码、参考论文全文或浏览器 Cookie。

当前尚未实现“Codex 独立登录机构并全自动下载订阅论文”。检索、候选筛选和论文阅读总结已经可用；受限全文仍由用户交互访问。此限制不影响本地导入或公开全文下载。

## 3. 文献质量、作者消歧和课题组关系仍需人工核实

检索质量理由来自可访问的论文资料和 Codex 判断，不等同于完整同行评审。仅能访问摘要时必须保留局限说明；引用数未知时显示未知。来源链接限制为 IEEE 论文详情页，不能保证网页长期不变。

详情页关联范围为当前完整本地论文库；联网检索另支持自然语言指定作者/课题组和研究主题，并可选择本地参考论文解析“这篇论文”等指代。结果展示需求拆解、共同署名、主题相似点与团队关系来源。缺少参照时先澄清，缺少关系证据时排除候选，不用纯主题匹配冒充同组。

相同署名可能属于不同的人，至少两位共同署名或共同通信作者只标为潜在团队，并展示理由；未接入 ORCID、IEEE Author ID 或机构知识图谱，不会确认性地宣称属于同一课题组。在线团队依据限定为 IEEE 或高校机构来源，仍标为潜在关系、待核实。通信作者只从原文明确标签识别，扫描件、复杂分栏及不规范署名可能显示未识别。第一作者指署名顺序第一位，未进一步判定共同第一作者。

## 4. 账号与迁移边界

v1.0.0 不提供机构账号或凭据文件查看器，也不在仓库、应用设置、论文缓存或日志中保存单位域名、账号、密码与浏览器会话。

Git 与迁移脚本继续排除私有目录、凭据文本、浏览器资料和会话文件，防止误复制到工程后进入迁移包。

迁移到另一台电脑时，不要复制浏览器会话或任何机构登录资料；需要受限全文时由用户在目标电脑自行登录官方页面。
